# Sajag — 44-second demo video (script + flow)

**Format:** 1920×1080, 30 fps, 44 s. The phone mockup is centred and shows real screen captures of the live app; motion-graphics text and callouts sit around it. Dark, calm palette (status colours only).
**Voice-over:** Deepgram Aura-2 "Harmonia", English, about 95 words.
**Music:** none (no licensed track). Light UI "tick" accents are optional.
**End card:** sajag-app.vercel.app + QR code + Team Tokenizers.
